# D32. The documents name no maintainer

Status: Decided.

The maintainers decided on 2026-11-15 that the documents of this repository
do not name a maintainer, because there will be more than one. A document says
"the maintainers" for a choice and "a maintainer" for a request.

The decisions that named a maintainer were changed to that wording when they
moved to this folder (D23). Their facts and dates did not change.

The copyright line of `LICENSE` names its holder, and it stays, because a
license needs one. The history of git keeps the old wording.
